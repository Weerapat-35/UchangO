# ระบบการเงิน + เงินเดือนช่าง + Dashboard

1. เปิด Supabase SQL Editor
2. รัน `20260927_finance_payroll.sql`
3. เปิดเว็บและเข้า `/admin`
4. ตรวจ Dashboard ใหม่: เงินเข้า/ออกวันนี้, เงินสุทธิ, กราฟเงินเข้า-ออก 14 วัน, ภาระงานช่าง และทางลัด
5. ตรวจ `/admin/finance`
6. ตรวจ `/admin/payroll`

Dashboard จะใช้ `finance_transactions` เป็นตัวเลขเงินจริงของเงินเข้า/ออก ส่วนกราฟรายได้จากการจองเดิมยังคงไว้เป็นข้อมูลมูลค่าบริการจากงานที่ยืนยัน/เสร็จสิ้น

หมายเหตุ: ไม่ต้องนำ `.env.local` หรือ Secret ใด ๆ เข้า Git/ZIP
